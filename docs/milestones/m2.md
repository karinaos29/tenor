# M2 · Understand

**Goal (architecture doc, Day 2):** entity extraction, offer tracker with change detection, replay mode, the two scripted test calls. **Demo: the offer card fills live.** (The event bus and replay source came early, in M1.)

## What was built
```
backend/
  pipeline/numbers.py     spoken numbers -> digits ("forty-two cents" -> "42 cents"), with a map back
                          to the original words for highlighting; fractions of a percent
  pipeline/extractor.py   stage 1 rules: price, percent, quantity, deadline, payment, fee, person, firm,
                          ticker (spelled letters, symbols, company names) + clear claims (price moves,
                          guarantees, fund expense ratios). Stage 2 Gemini, async, only for event lines
                          ("signed a deal") and unknown names; quotes must match what was said
  pipeline/llm.py         Gemini wrapper: Pydantic schema, client-side budget, fallback, token logging
  pipeline/offer.py       offer state machine: caller's words only, TermChange history, computed total
  pipeline/session.py     + extractor and tracker; end-of-call chain so nothing is cut off
  providers/catalog.py    fictional companies/firms + curated real tickers (names only)
  fixtures/calls/         scam_kstl.wav, honest_voo.wav; scripts/*.txt; expected/*.json; make_calls.py
frontend/src/
  components/OfferCard.tsx   offer rows with "said at m:ss", "(was …)", computed total, unsure "?"
  components/CallStrip.tsx   caller name · firm
  lib/highlight.ts           underline offer terms in the transcript
```

## What was measured
Real-time replays through real Deepgram and Gemini (`uv run python -m audio.replay …`):

| Stage | scam_kstl (2:14) | honest_voo (1:54) |
|---|---|---|
| `extractor.rules` median | 1 ms (n=24) | 1 ms (n=23) |
| `offer` median | < 1 ms (n=8) | < 1 ms (n=5) |
| `llm.extract` | 4.5 s median, 2 of 2 ok | 0 calls (rules covered it) |
| `stt.partial_lag` median / p95 | 310 / 635 ms | 297 / 624 ms |
| `stt.final_lag` median / p95 | 823 / 2072 ms | 779 / 1829 ms |

- **scam_kstl: the final offer matches `expected/scam_kstl.json` exactly**: Daniel Reeves · Hartwell & Crane, KSTL · Kestrel Motors, $0.42 a share, 10,000 shares (was 5,000), $4,200 (was $2,100), today at 3:00 PM, bank transfer. This held although Deepgram wrote "42¢" and "3PM today".
- **honest_voo:** firm, VOO, the April 15 deadline and the 0.03% expense-ratio claim are correct, with no false guarantee claim from "past returns don't guarantee…". Real audio exposed two bugs, both fixed afterwards and covered by regression tests on Deepgram's exact strings (`tests/test_deepgram_formats.py`), **not re-verified by another full replay**:
  - "Hello, is this Eszter?" was heard as "This is Esther." and taken as the caller's name. Fixed: full names and "my name is" now outrank a single word.
  - "a quarter percent" came back as "025%" and was read as 25%. Fixed: a leading zero means a dropped decimal point (0.25%).
- Tests: backend **211 passed** (+2 opt-in live tests), frontend **50 passed**, typecheck clean, build OK. Browser: the scam replay filled the offer card live at 1280 px, with "(was …)", the computed total, the caller in the strip, and underlined terms.
- Gemini, same structured request: `gemini-3.1-flash-lite` 1.3–5.4 s, `gemini-3.5-flash-lite` 8–30 s with timeouts, `gemini-3.8-flash` timed out. Hence 3.1-flash-lite and the async 8 s budget (see decisions).

## What's left / known issues
- **Diarization merges similar voices.** With two female macOS voices, Deepgram put both sides on one speaker, so every caller line was labeled "You" and the offer stayed empty. The honest call now uses a male caller voice. **The product fix is still open:** split a merged speaker by per-utterance loudness (the phone audio is about 8 dB quieter). Proposed as a separate task.
- **The test calls use macOS voices.** Gemini TTS stopped responding after 12 of 42 lines. `uv run python fixtures/calls/make_calls.py` swaps in the natural voices once it responds.
- **Gemini latency is erratic** (1–30 s). Nothing on screen waits for it, but the research agent (M3, planned on `gemini-3.8-flash`) needs a re-check, and possibly a different model or data-only checks.
- Claims are extracted but not shown until M3 adds the checker.
- Mishearings remain in the transcript ("fun fact sheet", "drags the 500"). The extractor works on the words that matter.

## Demo script (M2)
1. On the Start screen, press **Replay a test call** and pick **Pushy share offer**.
2. Watch the offer card fill in as the caller speaks: stock, price, then "10,000 shares (was 5,000)" and the total "$4,200 (was $2,100)". The caller's name appears in the top strip, and each term is underlined in the transcript.
3. Replay **Bank adviser, index fund**: a calm call with a real fund, a 0.25% fee and a real April 15 deadline. No price or quantity terms, because none were offered.
